# Модель на GPU-компьютере

Сервис (FastAPI, ffmpeg, правила) работает на одном компьютере, модель — на другом, с видеокартой:
`llama-server` с Qwen3-VL-30B-A3B (Q4_K_M, нужно ~24 ГБ видеопамяти). Сервис ходит к нему через
SSH-туннель, адрес остаётся `127.0.0.1:8080` — для сервиса модель «локальная», кадры не покидают
наши компьютеры (ТЗ, раздел 7).

```
компьютер сервиса: FastAPI ── 127.0.0.1:8080 ══ SSH ══► GPU-компьютер: llama-server
```

## 1. Сборка и модель (на GPU-компьютере, один раз, ~30–60 мин)

```bash
bash gpu/setup.sh
```

Собирает llama.cpp `b11669` с CUDA, качает модель (~19 ГБ) в `~/dalel/models` и создаёт ключ
сервера `~/.dalel_key`.

## 2. Сервер модели

```bash
bash gpu/serve_model.sh
```

## 3. Туннель и сервис (на компьютере сервиса)

```bash
ssh -N -L 8080:127.0.0.1:8080 <логин>@<GPU-компьютер>
```

В другой вкладке (ключ скопировать из `~/.dalel_key` GPU-компьютера в `~/.dalel_key`, в репозиторий не класть):

```bash
curl -s -H "Authorization: Bearer $(cat ~/.dalel_key)" http://127.0.0.1:8080/v1/models
./scripts/serve.sh
```

Кэш ответов разделён по имени модели: ответы разных моделей не смешиваются.
